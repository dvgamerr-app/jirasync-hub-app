// what you get

          
Built for people who live in Jira all day.

          

            Everything is stored on your machine first. Your API token lives in the OS credential
            store, not in a config file.
          

          

            

              

                
              

              
Offline-first, incremental sync

              

                A background pull every hour fetches only what changed since the last run. Your
                local database is the source of truth, so the table opens instantly.
              

              

                Jira Cloud→ pull →IndexedDB→your edits→ push diff →Jira Cloud

Honest time totals

              
Teammates’ worklogs are read-only and never counted in your hours.

            

            

              

                
              

              
Monthly CSV export

              

                One row per ticket per month. Opens cleanly in Excel and warns about unpushed time.
              

            

            

              

                
              

              
Token in the keychain

              
Windows Credential Manager and macOS Keychain keep your API token safe.

            

            

              

                
              

              
Multiple Jira sites

              
Add several Cloud accounts and map the story point field per project.

            

            

              

                
              

              
Discard per task

              
Changed your mind? Restore one ticket from Jira without touching the rest.

// get started

              
Up and running in two minutes.

              

                You need a Jira Cloud site (*.atlassian.net), your
                Atlassian email and an
                API token.
              

              
    
                
  1. 
                  Download the installerGrab the build for your OS from the latest release.
                
    2. 
                
  2. 
                  Add your accountSettings → Add Account, enter instance, email and token, then Save &
                    Connect.
                
    3. 
                
  3. 
                  SyncPull your projects, tasks and worklogs into the local table.
                
    4. 
                
  4. 
                  Edit and pushWork as you like, then press the upload button to send only what changed.
                
    5.
